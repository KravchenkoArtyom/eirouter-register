# Свой почтовый сервис

Кроме встроенных `tmail` и `mail.tm` можно добавить любой сайт временной
почты: панель спросит адрес страницы и предложит описать её шагами — как
создать ящик, как обновить список писем, как открыть письмо. Python править
не нужно.

Раздел панели: **«Почта»**. Файлы сервисов — `mail_services/имя.json`
(удалённые уезжают в `mail_services/_trash/`). Свои сервисы появляются в
списках почты в «Запуске», в сценарии и в шаге `mail_create`. Файлы с именем
на `_` служебные и в списках не показываются — например образец
`mail_services/_example_temp_mail.json`.

## Как добавить за пять минут

1. «Почта» → «Добавить сервис»: имя латиницей (станет id), адрес страницы и
   заготовка шагов.
2. Заготовки: **пустая**, **кнопка «Создать» и поле имени**, **адрес выдаётся
   сразу**, **адрес по кнопке «Копировать»**. Выберите близкую — потом
   поправите.
3. Нажмите «Открыть в инспекторе»: страница почты покажется внутри панели.
   Клик по элементу забирает селектор, кнопка «Новым шагом» кладёт его в
   нужную секцию сервиса.
4. «Проверить» покажет ошибки описания, «Сохранить сервис» запишет файл.
5. В «Запуске» выберите свой сервис (или укажите его в поле `mail`
   сценария) — дальше он работает как встроенный.

## Что заполнить

| Поле | Зачем |
| --- | --- |
| `name` | id сервиса: латиница, цифры, дефис |
| `label` | как показывать в списках |
| `url` | страница почты, открывается в отдельной вкладке |
| `poll_interval` | пауза между попытками найти письмо, с (по умолчанию 3) |
| `address.source` | откуда взять адрес: `value` (поле ввода), `text` (текст элемента), `attribute`, `clipboard` (кнопка «Копировать»), `page` (искать по всему тексту страницы) |
| `address.selectors` | список селекторов в порядке приоритета |
| `address.attribute` | имя атрибута для `source: attribute` |
| `address.timeout` | сколько ждать появления адреса, с |
| `code.length` | длина кода подтверждения (по умолчанию 6) |
| `code.keywords` | слова рядом с кодом: `code, код, verification` |
| `link.keywords` | слова в ссылке подтверждения: `verify, confirm` |
| `link.exclude` | что ссылкой подтверждения не считать: `privacy, terms, unsubscribe` |

## Три секции шагов

| Секция | Когда выполняется |
| --- | --- |
| `create` | один раз при создании ящика: нажать «Создать», вписать имя, дождаться адреса |
| `refresh` | перед каждой попыткой найти письмо: кнопка «Обновить», иногда просто пауза |
| `open_message` | чтобы прочитать письмо: клик по строке письма, ожидание тела |

Шаги — те же, что в сценариях сайта (`fill`, `click`, `wait`, `wait_visible`,
`press`, `dom`, `wait_random`, `notify`…), кроме почтовых: внутри почтового
сервиса они не нужны. Подстановки: `{username}`, `{login}`, `{password}` —
данные текущего аккаунта.

Если `open_message` пустая, письмо читается прямо со страницы списка: для
многих сервисов этого достаточно.

## Пример

```json
{
  "name": "my-temp-mail",
  "label": "My Temp Mail",
  "url": "https://mail.test/inbox",
  "poll_interval": 3,
  "address": {"source": "value", "selectors": ["#address"], "timeout": 60},
  "code": {"length": 6, "keywords": "code, код"},
  "link": {"keywords": "verify, confirm", "exclude": "unsubscribe"},
  "create": [
    {"action": "click", "selectors": ["button:has-text('Создать')"]},
    {"action": "wait_visible", "selectors": ["#address"], "timeout_ms": 15000}
  ],
  "refresh": [{"action": "click", "selectors": ["button:has-text('Обновить')"]}],
  "open_message": [{"action": "click", "selectors": [".mail-item"]}]
}
```

Дальше сервис умеет всё, что и встроенные: `mail_create`, `mail_refresh`,
`mail_wait_code`, `mail_wait_link`, `mail_open_link` — см.
[mail-actions.md](mail-actions.md).

## Как программа читает письмо

1. Выполняет `refresh`, ждёт `poll_interval` и повторяет до таймаута шага.
2. Открывает письмо шагами `open_message` (если они есть).
3. Ищет код: последовательность нужной длины рядом со словами из
   `code.keywords`; если ключевых слов нет — первое подходящее число.
4. Ищет ссылку: `http(s)`-ссылку со словами из `link.keywords`, отбрасывая
   `link.exclude`; если ключевых слов нет — первую ссылку письма.

Разбор письма живёт в `universal/mail_text.py`, исполнение шагов —
в `universal/scripted_mail.py`, реестр сервисов — в
`universal/mail_services.py`.

## Если что-то не так

| Симптом | Что проверить |
| --- | --- |
| «адрес не найден» | `address.source` и селекторы: снимите их инспектором на живой странице |
| адрес пришёл с мусором | `source: text` цепляет лишнее — возьмите `value` или уточните селектор |
| письмо не находится | добавьте в `refresh` кнопку обновления и увеличьте таймаут шага `mail_wait_code` |
| код неверный | задайте `code.length` и `code.keywords` |
| открылась не та ссылка | сузьте `link.keywords`, добавьте `link.exclude` |

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/mail/services` | список сервисов (встроенные + свои) |
| GET | `/api/mail/templates` | заготовки шагов |
| POST | `/api/mail/services` | создать сервис |
| GET PUT DELETE | `/api/mail/services/{name}` | чтение / запись / перенос в `_trash` |
| POST | `/api/mail/services/validate` | проверка без записи |
| GET | `/api/mail-services` | короткий список для выпадающих меню |
