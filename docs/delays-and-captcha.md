# Задержки, капча и уведомления

Три связанные вещи: программа делает паузы между действиями, замечает капчу
и зовёт человека. Настройки живут в панели («Запуск» → карточка «Задержки,
капча и уведомления») и хранятся в `webui.local.json` — файл локальный, в
репозиторий не попадает.

## Задержки

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| `step_min_ms` / `step_max_ms` | 150 / 600 | случайная пауза перед каждым шагом |
| `click_extra_ms` | 250 | добавка к паузе перед нажатиями |
| `after_captcha_s` | 3 | тишина после решённой капчи, прежде чем идти дальше |
| `account_min_s` / `account_max_s` | 0 / 0 | пауза между аккаунтами очереди |

Пауза между аккаунтами прерывается кнопкой «Остановить»: очередь не будет
держать вас лишние минуты. Внутри сценария пауза ставится шагом
`wait_random` (границы «от» и «до», в секундах) или обычным `wait`.

Задержки сценария можно записать прямо в его JSON — тогда они действуют,
если панель не передала свои:

```json
"delays": {"step_min_ms": 300, "step_max_ms": 900, "account_min_s": 20, "account_max_s": 60}
```

## Капча

Программа капчу **не решает**. Она её замечает, останавливает сценарий и
зовёт человека. Проверка ищется после каждого перехода и после действий,
которые меняют страницу (`click`, `press`, `goto`, `select`), а также сразу
после открытия страницы.

Что распознаётся: reCAPTCHA, hCaptcha, Cloudflare Turnstile, страница
проверки Cloudflare, Arkose/FunCaptcha, GeeTest, а также общие признаки
(`iframe[src*="captcha"]`, `.captcha`, `#captcha`). Дополнительно — текст на
странице: «я не робот», «подтвердите, что вы человек», «i'm not a robot» и
похожие (выключается галочкой). Свои селекторы добавляются в поле «Свои
признаки капчи» через запятую.

### Четыре режима

| Режим | Поведение |
| --- | --- |
| `wait` (по умолчанию) | ждать человека до «Сколько ждать» (300 с); каждые 30 с напоминание в логе; не решена — аккаунт помечается неудачным |
| `pause` | выждать «Пауза, с» (20 с) и продолжить; кнопки панели и исчезновение капчи прерывают паузу досрочно |
| `stop` | не ждать: аккаунт пропускается, очередь идёт дальше |
| `log` | только записать в лог и продолжить (для отладки) |

### Как вас зовут

Когда капча найдена, в панели поверх всех разделов появляется полоса:
название проверки, шаг, селектор и адрес страницы, счётчик ожидания и три
кнопки:

- **«Я решил, продолжай»** — сценарий идёт дальше (после паузы
  `after_captcha_s`);
- **«Пропустить аккаунт»** — этот аккаунт пропускается, очередь продолжается;
- **«Остановить запуск»** — очередь прекращается.

Вместе с полосой: короткий звук, всплывающее сообщение и системное
уведомление браузера (первое включение спросит разрешение). Звук и
уведомления выключаются галочками. В консольном запуске (`py -3 -m universal`)
вместо полосы — сигнал в терминале и строка в логе.

Последние события видны под логом («Уведомления»), а весь лог запуска лежит
в `logs/runs/run_<дата>_<id>.log` — рядом с ним `.json` с итогом (сколько
готово, неудач, пропущено). Если аккаунт упал, снимок экрана, HTML и текст
ошибки остаются в `logs/failures/<id запуска>/`.

Несколько аккаунтов одновременно («Одновременно» в разделе «Запуск», до 4)
ускоряют очередь, но капчу придётся решать в нескольких окнах браузера — и
сайт быстрее заметит поток однотипных регистраций. Для человекоподобного
поведения оставьте 1 и увеличьте паузы между аккаунтами.

## Шаги для этих случаев

| Шаг | Поля | Зачем |
| --- | --- | --- |
| `captcha_wait` | `timeout`, `message` | явно дождаться решения там, где капча ожидаема |
| `wait_random` | `min_seconds`, `max_seconds` | случайная пауза |
| `notify` | `message`, `level` | позвать человека («проверьте телефон») или пометить место в логе |

Группа в форме шага — «Капча и уведомления».

## Консоль

```powershell
py -3 -m universal --scenario universal_scenarios/my-site.json --count 5 ^
  --captcha-mode wait --captcha-timeout 300 ^
  --step-delay 200 800 --account-pause 30 90
```

`--captcha-mode wait|pause|stop|log`, `--captcha-timeout СЕК`,
`--step-delay MIN_MS MAX_MS`, `--account-pause MIN_S MAX_S`.

## Настройки в JSON

`webui.local.json` (создаётся панелью):

```json
{
  "captcha": {"enabled": true, "mode": "wait", "timeout": 300, "poll": 3,
              "pause_s": 20, "check_text": true, "selectors": ["#my-captcha"]},
  "delays": {"step_min_ms": 150, "step_max_ms": 600, "click_extra_ms": 250,
             "after_captcha_s": 3, "account_min_s": 0, "account_max_s": 0},
  "proxy": {"mode": "per_account", "ban_after": 2},
  "notify": {"sound": true, "desktop": true, "toast": true}
}
```

Код: `universal/captcha.py` (поиск и режимы), `universal/pacing.py` (паузы),
`universal/control.py` (связь запуска с человеком), `webui/config.py`
(хранение настроек).
