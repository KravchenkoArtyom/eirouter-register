# Инспектор: выбор элементов на странице сайта

Инспектор открывает страницу сайта в headless-браузере на этой машине и
показывает её внутри панели. Это не картинка: сервер отдаёт «зеркало» —
сериализованный DOM настоящей страницы со своего адреса, поэтому подсветка при
наведении и выбор элемента работают мгновенно, без запросов на каждое движение
мыши.

## Как пользоваться

1. Раздел «Инспектор» → адрес (пусто — возьмётся адрес текущего сценария) →
   «Открыть».
2. Наведите курсор: элемент обводится, сверху показывается его тег, id, классы
   и размер, в строке состояния — путь до элемента.
3. Клик — панель «Элемент» заполняется кандидатами селекторов, предлагает
   действие (`fill`, `click`, `check`, `select`) и подходящую подстановку
   (`{email}`, `{password}`, `{code}` и т. п.).
4. «Проверить» проверяет селектор **на настоящей странице**: сколько элементов
   найдено, уникален ли, видим ли.
5. Дальше на выбор: «В буфер» (или Shift+клик по элементу), «В выбранный шаг»,
   «Новым шагом». Куда именно попадёт шаг, задают списки «Куда добавлять шаги»
   и «Место» (в конец или после выбранного шага).

Кандидаты помечены: `[1]` — селектор уникален, число — сколько элементов нашёл,
`[PW]` — селектор Playwright (`:has-text(...)`), который проверяется только на
настоящей странице.

## Буфер элементов

Временное хранилище: снятые элементы лежат в `webui_elements.json` рядом с
проектом и не пропадают при перезагрузке панели или перезапуске WebUI. Из
буфера элемент отправляется в шаги по одному («→ шаг») или все сразу
(«Все в шаги»); «Очистить» опустошает буфер. В репозиторий файл не попадает.

## Действие на настоящей странице

Зеркало показывает страницу в её текущем состоянии. Чтобы дойти до нужного
экрана (открыть вкладку «Регистрация», закрыть баннер, прокрутить), выполните
действие на настоящей странице: `click`/`fill`/`press`/`check` по текущему
селектору, `scroll`, `reload`, `back` — зеркало обновится.

## Режим «Кадр»

Резервный режим: скриншот страницы, клик по нему определяет элемент через
`elementFromPoint` на сервере. Пригодится, если зеркало собралось неудачно
(тяжёлая динамическая вёрстка) — подсветки при наведении в нём нет.

## Что делает сервер

- скрипты сайта из зеркала вырезаны, внешние фреймы не подгружаются, `<base>`
  подставлен: стили и картинки берутся с сайта, а клики никуда не ведут;
- текущие значения полей переносятся в зеркало, чтобы оно совпадало с реальным
  состоянием формы;
- одновременно живут не больше трёх сессий инспектора, лишние закрываются;
- «Закрыть» освобождает браузер сразу.
