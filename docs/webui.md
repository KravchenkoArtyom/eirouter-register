# Панель (WebUI)

Запуск: `scripts\webui.bat` или `py -3 -m webui [--port 8765]`,
адрес http://127.0.0.1:8765 (только localhost). Нужны `fastapi` и `uvicorn`
из `requirements.txt`. Регистрация идёт в том же процессе, в фоновом потоке.

Оформление — нейтральная гамма без ярких цветов и тонкие границы. Тема
переключается в шапке: «Авто» (по настройке системы), «Светлая», «Тёмная»;
выбор запоминается в браузере. Зеркало сайта в инспекторе всегда показывается
в собственном оформлении страницы.

## Как устроен интерфейс

- **Семь разделов в шапке**: Обзор, Запуск, Сценарий, Почта, Прокси,
  Инспектор, Аккаунты. Раздел один на экране — ничего не прячется в
  подменю. Под шапкой строка состояния: сколько сценариев, аккаунтов,
  прокси, своих почт и виден ли AdsPower.
- **Обзор** — схема работы и чеклист «с чего начать»: каждая строка
  говорит, готова ли часть, и ведёт в нужный раздел.
- **Полоса капчи** живёт поверх всех разделов: что бы вы ни смотрели, зов о
  помощи виден, а кнопки ответа рядом.
- **Правки живут в памяти** до кнопки «Сохранить»; рядом всегда написано,
  сохранено или нет, а «Проверить» показывает ошибки до записи.
- **Формы собираются из каталога** действий и сервисов: у каждого действия
  ровно свои поля, поэтому лишнего на экране нет.
- **Опасное — с подтверждением**: удаление уносит файл в `_trash/`, а не
  стирает.
- Тексты — обычными словами, термины поясняются подсказкой под полем.

## Разделы

**Обзор.** Схема «как это работает» (та же, что в
[how-it-works.md](how-it-works.md)) и чеклист готовности: сценарии, почта,
прокси, браузер, капча.

**Запуск.** Сценарий, количество аккаунтов, почта, сеть (файл `proxies.txt`,
один адрес вручную или напрямую) и правило ротации, браузер
(авто/Chrome/AdsPower), прогресс, живой лог, последние уведомления и таблица
прокси запуска. Ниже — карточка «Задержки, капча и уведомления»
(см. [delays-and-captcha.md](delays-and-captcha.md)): паузы между шагами и
аккаунтами, режим капчи, свои признаки, звук и системные уведомления.
«Остановить» завершает очередь после текущего аккаунта и прерывает паузу.

**Сценарий.** Список сценариев и кнопки «Новый», «Дублировать», «Удалить»,
«Проверить», «Сохранить». Ниже — секции (`steps`, `verification`, `submit`,
`success`), список шагов и форма шага. Форма собирается из каталога действий,
поэтому у каждого действия ровно свои поля. Шаг можно добавить после
выбранного или в конец, продублировать, передвинуть, удалить и перенести в
другую секцию. Правки живут в памяти до «Сохранить сценарий».

**Почта.** Встроенные сервисы и свои: карточки списка, редактор полей
(адрес страницы, откуда брать адрес ящика, как искать код и ссылку) и те же
шаги — в трёх секциях: «Создать ящик», «Обновить письма», «Открыть письмо».
Подробно — [mail-services.md](mail-services.md).

**Прокси.** Список адресов текстом или файлом (можно перетащить), проверка
связи через `api.ipify.org`, правило ротации и «убирать после N неудач».
Подробно — [proxies.md](proxies.md).

**Инспектор.** Страница сайта открывается в браузере на этой машине и
показывается здесь: наведение подсвечивает элемент, клик забирает селекторы,
Shift+клик кладёт элемент в буфер. Готовый шаг кладётся в любую секцию
сценария **или почтового сервиса**. Подробнее — [inspector.md](inspector.md).

**Аккаунты.** Содержимое `*_accounts.json` без паролей и ключей.

Статика панели — ES-модули в `webui/static/js/` (`main.js` собирает разделы:
`runs`, `scenario`, `mail`, `proxies`, `inspector`, `accounts`, `overview`,
общий редактор шагов `steps.js`).

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/health`, `/api/environment` | состояние сервера и окружения |
| GET | `/api/actions`, `/api/templates`, `/api/mail-services` | справочники для интерфейса |
| GET PUT | `/api/settings` | задержки, капча, уведомления, правило прокси |
| GET POST | `/api/scenarios` | список / создание сценария |
| GET PUT DELETE | `/api/scenarios/{name}` | чтение / запись / перенос в `_trash` |
| POST | `/api/scenarios/validate` | проверка без записи |
| GET POST | `/api/mail/services`, `/api/mail/templates` | почтовые сервисы и заготовки шагов |
| GET PUT DELETE | `/api/mail/services/{name}` | чтение / запись / перенос в `_trash` |
| POST | `/api/mail/services/validate` | проверка описания сервиса |
| GET PUT DELETE | `/api/proxies` | список прокси: чтение, запись, очистка |
| POST | `/api/proxies/check` | проверка связи через каждый адрес |
| POST GET | `/api/runs`, `/api/runs/{id}` | запуск и его лог |
| POST | `/api/runs/{id}/stop` | остановить после текущего аккаунта |
| POST | `/api/runs/{id}/captcha` | ответ человека: `resolved`, `skip`, `stop` |
| GET | `/api/accounts` | аккаунты из файлов проекта |
| POST | `/api/inspect/start` | открыть страницу в инспекторе |
| GET | `/api/inspect/{sid}/state`, `/mirror`, `/shot` | состояние, зеркало, кадр |
| POST | `/api/inspect/{sid}/pick`, `/verify`, `/act` | элемент по точке, проверка селектора, действие на странице |
| DELETE | `/api/inspect/{sid}` | закрыть сессию |
| GET POST PATCH DELETE | `/api/buffer`, `/api/buffer/{id}` | временный буфер элементов |
